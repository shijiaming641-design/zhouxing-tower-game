# 布局流派图谱（内部研发用）

这份图谱基于当前代码里的布局定义与实际触发逻辑整理。

核心结论：

**当前项目已经有流派雏形，但这些流派应该先作为内部研发和平衡工具，而不是直接显示给玩家。**

现有布局不缺数量，缺的是内部边界、追求目标和局内兑现路径。

重要约束：

**不要在玩家界面直接显示“强攻流”“护甲防反流”“经济流”等标签。**

玩家的乐趣来自自己钻研出打法。我们内部可以用流派图谱做研发，但外部应该只给效果、条件、反馈和线索。

## 内部主流派图谱

### 1. 强攻压血流（内部名）

目标：

快速压低敌人血线，用短冷却、多段、穿透、暴击结束战斗。

当前组件：

| 位置 | 布局 |
|---|---|
| 通用 | 全体穿透、闪电突袭、双重打击、能量充能 |
| 时代 | 虎符压阵 |
| 职业 | 望闻问切、系统过载、记忆爆破、精算头脑 |
| 隐藏 | 绝对命中、嗜血斩 |

适配时代：

- 秦卷最强
- 中国卷次强
- 宋卷可玩但不是主推

当前判断：

这是目前最完整、最容易理解的流派。问题是它可能过于自然地成为默认最优解。

建议：

- 秦卷继续强化强攻，但要给它“拖久会亏”的压力。
- 非秦卷不要继续无脑强化伤害，否则时代差异会变薄。
- 战斗反馈可以强化压血与斩杀感，但不要直接告诉玩家“你在玩强攻流”。

---

### 2. 护甲防反流（内部名）

目标：

先吃住压力，再把护甲、反弹、延迟护甲转换成输出或容错。

当前组件：

| 位置 | 布局 |
|---|---|
| 通用 | 稳固防御、循环护盾 |
| 职业 | 固若金汤、相位护盾 |
| 隐藏 | 反伤光环、铁壁反震 |

适配时代：

- 宋卷最合适
- 中国卷也适合
- 秦卷不宜过强，否则会冲淡秦卷速攻人格

当前判断：

组件质量不错，但核心爽点藏得太深。真正的爆点是 `铁壁反震` 和 `反伤光环`，但它们现在更像“图鉴知识”，不是玩家能主动追求的目标。

建议：

- 在局内给玩家更明确的护甲状态变化和临界反馈，但不要直接显示“护甲防反流”。
- 商店、事件、休息点可以偶尔提供护甲流组件引导。
- 农民应该成为护甲防反流的第一推荐职业。

---

### 3. 控制节奏流（内部名）

目标：

不拼爆发，通过干扰、束缚、眩晕、跳过敌方行动来获得安全回合。

当前组件：

| 位置 | 布局 |
|---|---|
| 通用 | 战术干扰、束缚致命 |
| 职业 | 病毒植入 |
| 时代偏置 | 宋卷对控制收益有加成 |

适配时代：

- 宋卷最合适
- 中国卷也合适
- 秦卷只适合当辅助组件

当前判断：

方向是对的，但现在“控制到底改变了什么”还不够显眼。尤其战术干扰在实际战斗里更像轻伤害提示，玩家未必感到敌人真的被控住。

建议：

- 战术干扰需要更明确的战斗反馈。
- 控制类布局应该在 Boss 战有特殊价值，但不能完全锁死 Boss。
- 控制效果最好和“争取下一手空间”绑定，让玩家感到节奏被自己拖住了。

---

### 4. 续航稳局流（内部名）

目标：

通过回血、持续回血、满血转甲、护甲缓冲来拖过高压战。

当前组件：

| 位置 | 布局 |
|---|---|
| 通用 | 循环护盾 |
| 时代 | 山河同契 |
| 职业 | 妙手回春、五谷丰登、相位护盾 |
| 隐藏 | 嗜血斩 |

适配时代：

- 中国卷最合适
- 宋卷次合适
- 秦卷不宜成为主流

当前判断：

续航流已经有骨架，但目前更偏“保命”，还没有形成“拖到后期会赢”的反压能力。

建议：

- 续航流需要一个中后段转化点，比如满血时转攻击、护甲、机括或额外布局热度。
- 中国卷应该把这条路线做成终局压力下的主流派之一。
- 医生和流浪者应该明显更适合这条线。

---

### 5. 经济经营流（内部名）

目标：

用战斗收益转化为商店、材料、器物优势，让后续战斗越来越轻。

当前组件：

| 位置 | 布局 |
|---|---|
| 时代 | 市舶周转 |
| 职业 | 金钱帝国 |
| 隐藏 | 物资轰炸 |

适配时代：

- 宋卷主推
- 秦卷和中国卷只适合作为副线

当前判断：

概念很好，但当前经济流的战斗内存在感偏弱。它主要在胜利后返钱，玩家当回合不一定感到“我这套正在运转”。

建议：

- 宋卷要给经济流更多当场反馈。
- 经济流需要明确的路线配套，比如商队线、补给线、工造线。
- 物资轰炸可以成为经济流的战斗爆点，让“资源多”变成“能打死敌人”。

---

### 6. 低命翻盘流（内部名）

目标：

在血线危险时触发高收益，制造逆转回合。

当前组件：

| 位置 | 布局 |
|---|---|
| 隐藏 | 绝地反击 |
| 职业支撑 | 医生复起、妙手回春 |
| 续航支撑 | 山河同契、五谷丰登、嗜血斩 |

适配时代：

- 中国卷最合适
- 秦卷可以做高风险版本
- 宋卷不该主推

当前判断：

这是最有戏剧性的流派，但目前组件偏少。现在更像一个隐藏触发点，不像完整流派。

建议：

- 不要急着扩大成全职业流派。
- 先作为医生/中国卷的特色路线打磨。
- 需要更强的低命 UI 提示和触发前预热，否则玩家不会主动围绕它构筑。

---

### 7. 资源爆破流（内部名）

目标：

把背包、材料、道具、金币等局外/局内资源转化为战斗输出。

当前组件：

| 位置 | 布局 |
|---|---|
| 隐藏 | 物资轰炸 |
| 职业 | 金钱帝国 |
| 时代 | 市舶周转 |

适配时代：

- 宋卷最合适

当前判断：

这条线现在只是苗头。它和经济经营流高度相关，但还没独立出来。

建议：

- 暂时不要作为独立主流派推。
- 先作为宋卷经济流的终端爆点。
- 后续如果要扩展，可以加入“材料转甲”“金币买一回合优势”“消耗器物打爆发”。

## 时代与流派关系

| 时代 | 主推流派 | 副流派 | 不建议强化过多 |
|---|---|---|---|
| 秦卷 | 强攻压血 | 低命高风险、短控补节奏 | 长线续航、纯经营 |
| 宋卷 | 经济经营、护甲防反、控制节奏 | 资源爆破 | 纯爆发强攻 |
| 中国卷 | 续航稳局、低命翻盘、综合压制 | 强攻压血、控制节奏 | 单一经济流 |

结论：

**三卷最好不要只是数值偏置不同，而是鼓励玩家选不同流派。**

| 职业 | 当前最适合流派 | 次适合流派 |
|---|---|---|
| 医生 | 续航稳局、低命翻盘 | 强攻破防 |
| 黑客 | 控制节奏、无视护甲爆发 | Boss 压制 |

| 流浪者 | 综合稳局、基础输出 | 续航防御 |

当前问题：

职业专属布局已经有方向。开局选择页不应该直接提示职业流派，但战斗和事件可以让玩家逐步感到某些职业更容易走出某些打法。

## 当前最值得改的三件事

### 1. 建立内部流派归档，不对玩家显示

现在已有 `role`，但它更像功能定位。

可以在策划表、调试工具或内部文档里维护 `archetype`，但不要接入玩家 UI。

| 示例 | 标签 |
|---|---|
| 全体穿透、闪电突袭、双重打击 | 强攻压血 |
| 稳固防御、循环护盾、固若金汤 | 护甲防反 |
| 战术干扰、束缚致命、病毒植入 | 控制节奏 |
| 市舶周转、金钱帝国 | 经济经营 |
| 山河同契、妙手回春、五谷丰登 | 续航稳局 |
| 绝地反击 | 低命翻盘 |

用途：

- 内部平衡
- Boss 设计
- 事件奖励设计
- 商店/器物池权重设计
- 判断某条打法是否过强或过弱

玩家侧表达方式：

| 内部流派 | 玩家侧只看到 |
|---|---|
| 强攻压血 | 伤害更快、斩杀更明显、敌人血线被压低 |
| 护甲防反 | 护甲成势、碎甲、反震、敌人攻击被转化 |
| 控制节奏 | 敌方行动被拖慢、关键回合被争取出来 |
| 经济经营 | 战后收益、商店优势、物资周转 |
| 续航稳局 | 命数回稳、满命转甲、持续恢复 |
| 低命翻盘 | 命悬一线时出现反打机会 |
| 资源爆破 | 背包/物资转化为战斗爆点 |

### 2. 把隐藏布局变成局内追求目标

现在隐藏布局已经被放进图鉴，但玩家在局内未必知道自己“差什么”。

建议加三类提示：

| 条件 | 提示 |
|---|---|
| 装备妖刀 | 解锁嗜血斩追求 |
| 护甲接近 5 | 铁壁反震预热 |
| 背包接近满格 | 物资轰炸预热 |

目标：

让玩家产生“我快成型了”的感觉。

注意：

提示应该是状态变化，不是答案。例如可以做“护甲已成势”“商路兑现”“命线将断”，不要写“护甲防反流已成型”。

### 3. 让 Boss 成为流派考试

当前 Boss 压力已经有基础，但还可以更明确测试流派。

| 流派 | Boss 应该考什么 |
|---|---|
| 强攻压血 | 能不能在阶段转换前抢血 |
| 护甲防反 | 能不能扛住高压回合并反打 |
| 控制节奏 | 能不能把关键危险回合拖过去 |
| 续航稳局 | 能不能处理持续压力 |
| 经济经营 | 前面积累是否已经转化为器物优势 |
| 低命翻盘 | 是否能在濒危时完成反杀 |

## 我的判断

当前最成熟的流派：

1. 强攻压血
2. 护甲防反
3. 续航稳局

当前最有潜力但需要补表达的流派：

1. 经济经营
2. 控制节奏

当前最有戏剧性但组件还少的流派：

1. 低命翻盘
2. 资源爆破

下一步最值得做：

**先不要加新布局。先在内部用流派图谱做平衡和内容规划，但不要把流派名显示给玩家。**

更准确的下一步：

1. 内部维护布局归档。
2. 玩家侧只强化条件、效果和战斗反馈。
3. 图鉴写来源和触发条件，不写推荐流派。
4. Boss 用内部流派图谱设计考题，但不直接公布答案。

## 戏剧组件扩展原则

当前三步布局已经占满 27 种组合，不建议继续新增三步布局。后续增加戏剧性，优先走三条路：

| 路径 | 用途 | 玩家侧感受 |
|---|---|---|
| 既有隐藏布局分支 | 给已有条件追加临界收益 | “差一点死，但突然翻盘” |
| 器物/资源加压 | 让背包、金币、材料变成战斗爆点 | “我前面攒的东西现在炸出来了” |
| 事件/商店配套 | 给玩家更多追求组件的机会 | “这局好像能围绕某个条件成型” |

注意：

- 不在玩家界面显示内部流派名。
- 不新增三步布局，避免破坏已有 27 组合空间。
- 不让自动触发偷偷消耗高价值资源，除非文本和规则提前说清楚。
- 优先增强“触发瞬间的反馈”，再考虑扩容数值系统。

## 已落地的小步组件

### 低命临界强化

承载布局：绝地反击。

原逻辑：

- 命数 ≤ 30% 时触发。
- 本回合命中伤害 ×2。
- 获得 3 护甲。

新增临界层：

- 命数 ≤ 15% 时，护甲从 3 提升到 6。
- 同时获得 1 回合攻击 +1。
- 文本从普通“绝地反击”切到“命悬一线”，突出濒死爆点。

设计目的：

让低命路线不是只有一个触发条件，而是有更危险、更高收益的第二层临界点。

### 资源加压强化

承载布局：物资轰炸。

原逻辑：

- 背包满格时触发。
- 消耗 1 个背包物品造成固定伤害。

新增加压层：

- 持有材料会提高伤害。
- 材料加压最多 +3。
- 不消耗材料。

设计目的：

让资源线在战斗中有当场存在感，同时避免玩家误以为系统“偷花材料”。

## 四步终式均摊

四步布局作为额外组合空间，不占用三步 27 格。内部按七条研发方向先各补 1 个终式，保证每条路线都有一个更长、更有仪式感的兑现点。

| 内部方向 | 四步布局 | 序列 | 玩家侧效果 |
|---|---|---|---|
| 强攻压血 | 破阵连环 | △△□△ | 造成更高全体伤害 |
| 护甲防反 | 山岳回震 | □□△□ | 获得高护甲并进入反击态 |
| 控制节奏 | 连环锁势 | △□○□ | 造成伤害并眩晕 |
| 续航稳局 | 生息轮转 | □○□○ | 持续恢复命数 |
| 经济经营 | 商潮回涌 | ○□□○ | 胜利后获得更多金币 |
| 低命翻盘 | 残灯逆照 | ○○△□ | 低命时触发反扑 |
| 资源爆破 | 倾仓齐发 | △△○□ | 背包满格时消耗物品打爆发 |

实现原则：

- 四步终式默认走高级研习解锁，不塞进新手初始认知。
- 四步触发按最长匹配优先，避免同一串输入同时白嫖三步后缀。
- 玩家只看到布局名、序列、条件和效果；内部方向不作为 UI 标签展示。
- 后续如果继续扩容，优先给每条方向补“事件/器物/敌人考题”，不要先继续堆布局数量。

## 下一批优先组件

### 低命线

建议优先做：

| 组件 | 承载位置 | 效果方向 |
|---|---|---|
| 残灯护身 | 器物或事件祝福 | 每场战斗首次跌入低命时获得护甲 |
| 断线反扑 | 绝地反击升级 | 低命命中后少量回血或回机括 |
| 濒危预热 | 战斗反馈层 | 血线接近 30% 时给强提示，但不直接告诉答案 |

暂时不要做：

- 全职业大量低命奖励。
- 低命无脑免死。
- 低命自动胜利。

原因：

低命爽点来自“危险但可控”，不是系统替玩家兜底。

### 资源线

建议优先做：

| 组件 | 承载位置 | 效果方向 |
|---|---|---|
