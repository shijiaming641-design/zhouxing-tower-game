# 周行循环三角 项目定位草案

## 1. 项目一句话

《周行循环三角》是一款以中国历史时代为题材包装的轻度 Roguelike 策略爬塔游戏，核心体验是用基础出招、布局连招、路线选择和器物构筑，在不同“时代卷”中完成一局又一局高压博弈。

## 2. 项目定义

这不是传统历史模拟游戏，也不是纯卡牌构筑游戏。

它更准确的定义是：

**中国历史题材包装下的轻策略 RogueLike。**

项目的核心结构由四层组成：

1. 基础博弈层：以出招克制为底层，形成低门槛、高反馈的即时判断。
2. 构筑层：角色、布局、器物、强化、事件奖励共同构成每局差异化 build。
3. 路线层：玩家在多分支历史路线中选择战斗、休整、商店、异闻节点。
4. 题材层：秦、宋、中国三个时代卷承担美术、规则偏置与叙事包装。

如果要一句话说明它“像什么”，更接近：

**《杀戮尖塔》式局内构筑 + 轻量猜拳/克制战斗 + 中国历史时代章节包装。**

## 3. 产品定位

### 类型定位

- 单机
- 轻中度策略
- Roguelike / Roguelite
- 爬塔构筑
- 历史题材风格化作品

### 用户定位

适合三类用户：

1. 喜欢反复开局、研究套路和 build 的 RogueLike 玩家。
2. 喜欢中国历史题材，但不想进入重度 SLG 学习成本的玩家。
3. 喜欢“规则简单，但组合很深”的独立策略游戏玩家。

### 平台定位

优先建议 PC 单机，尤其适合 Steam。

原因：

1. 单局结构清晰，适合桌面端反复游玩。
2. 美术和题材辨识度适合商店页展示。
3. 当前内容框架天然适合“买断制独立游戏”，不适合先做成长线数值运营。

## 4. 核心卖点

### 卖点 1：历史时代不是皮肤，而是规则卷

项目目前最有价值的设计，不是简单换一套皮肤，而是让秦卷、宋卷、中国卷分别代表不同风格：

- 秦卷：直接、强压、速决。
- 宋卷：运营、资源、反制。
- 中国卷：复合、终局、规则叠加。

这意味着“换时代”同时换玩法节奏，这是非常有效的内容扩展轴。

### 卖点 2：低理解门槛，高构筑空间

玩家很快就能理解出招克制，但很难在短时间穷尽：

- 职业差异
- 布局连招
- 器物联动
- 事件收益
- 商店运营
- 元进度强化
- 时代规则偏置

这类结构非常适合反复开局。

### 卖点 3：题材辨识度强

市面上很多 RogueLike 都是西幻、赛博或抽象符号化系统。这个项目最直接的竞争力，是把“国风历史章节”和“轻策略构筑”连在一起，形成视觉和叙事记忆点。

### 卖点 4：可持续扩展

项目非常适合持续加内容：

- 新时代卷
- 新职业
- 新布局分支
- 新器物流派
- 新事件池
- 新 Boss 机制

这说明它不仅能做 demo，也有继续做成正式产品的空间。

## 5. 当前玩法概括

当前版本适合对外表述为：

1. 选择时代卷。
2. 选择职业角色。
3. 配置本局初始布局。
4. 在历史地图上选择路线推进。
5. 通过战斗、商店、休整、异闻获取成长。
6. 利用角色能力、布局和器物形成构筑。
7. 挑战该时代卷 Boss。
8. 获取局外资源，解锁新强化和新内容。

### 战斗体验的正确表述

不建议只说“猜拳战斗”。

更好的说法是：

**以克制出招为底层的轻策略回合战斗。**

因为项目真正的深度不在单次猜拳，而在：

- 什么时候出基础招
- 什么时候攒布局
- 什么时候打爆发
- 什么时候转防守
- 什么时候为商店或事件收益改路线

## 6. 适合对外使用的定位文案

### 版本 A：最简版

《周行循环三角》是一款中国历史题材的轻策略 Roguelike 爬塔游戏。你将在不同时代卷中选择角色、布局与路线，用克制博弈和器物构筑一路推进，完成属于自己的通关节奏。

### 版本 B：偏商店页

在秦、宋与中国三大时代卷中，选择你的角色与初始布局，踏入一场场高压历史爬塔。通过战斗、异闻、商店和休整不断塑造构筑，在低门槛高深度的克制博弈中，走向每个时代的终局之战。

### 版本 C：偏发行 / 路演

这是一款以中国历史叙事为包装、以轻策略构筑为核心的单机 Roguelike。项目用“时代卷”替代传统章节设计，让不同历史阶段同时承担视觉风格、成长节奏和规则偏置，使内容扩展具备天然模块化优势。

## 7. 项目现阶段的优势

从当前工程状态看，项目已经具备以下产品基础：

1. 已有明确主循环，不是概念阶段。
2. 已有三套时代卷框架，不是单一主题试玩。
3. 已有角色差异、布局系统、器物系统、地图系统、异闻系统、商店系统、Boss 终局。
4. 已有局外成长，说明具备反复游玩基础。
5. 已有一批测试脚本，说明平衡和系统验证意识比较强。

这意味着项目最大的任务不再是“有没有玩法”，而是“如何把玩法说清楚、打磨节奏、形成对外识别”。

## 8. 当前主要风险

### 风险 1：对外表达容易失焦

如果只说“猜拳爬塔”，项目会显得过轻。

如果只说“历史策略游戏”，项目又会让人误以为是重度 SLG。

它需要一个中间定义：

**历史题材轻策略 RogueLike。**

### 风险 2：题材与机制之间还需要更强绑定

目前时代卷的规则差异已经有了，但后续仍需要继续强化：

- 为什么这套规则属于“秦”
- 为什么这套收益属于“宋”
- 为什么“中国卷”是规则叠加的终局

只有这样，时代卷才不是换皮章节，而是世界观和机制一体化。

### 风险 3：最核心爽点需要更集中

项目现在元素较多，容易出现“系统很多，但第一印象不够尖”的问题。

后续应该持续强化一个中心感受：

**在高压时代卷里，用一套越来越成型的构筑，顶着压力往上走。**

## 9. 前景判断

### 短期前景

有望做成一个完成度较高的独立游戏原型，具备对外展示、试玩和继续融资/找合作的基础。

### 中期前景

如果把节奏、引导、美术统一性和数值平衡补齐，这个项目有机会成为一款“题材辨识度很强的小而精 RogueLike”。

### 长期前景

项目的长期价值不在海量数值运营，而在“时代卷”这个扩展模型：

- 可以继续做新的历史卷
- 可以做 DLC 式扩展
- 可以追加职业和器物流派
- 可以逐步沉淀成一个独立 IP 原型

## 10. 建议的商业定位

当前最适合的商业方向：

**Steam 买断制独立单机游戏。**

不建议一开始按以下方向理解：

- 大型历史 SLG
- 长线数值养成手游
- 重叙事 AVG

原因是当前项目的最大优势在“循环好玩”和“章节差异明显”，不是长线社交、海量剧情或重数值商业化。

## 11. 建议的一句话品牌主张

可以从下面几句里选方向：

1. 在时代高压中构筑你的胜路。
2. 一局一时代，一卷一打法。
3. 用你的布局，穿过中国历史的高压终局。
4. 在秦、宋与终局中国之间，走出属于你的爬塔节奏。

## 12. 项目名建议方向

“周行循环三角”本身有辨识度，但第一眼不够解释玩法。

建议保留它作为正式名时，同时准备一个副标题或宣发说明，例如：

- 周行循环三角：时代卷
- 周行循环三角：山河爬塔
- 周行循环三角：百代终局

如果后续考虑更直接的市场表达，也可以评估“双标题结构”：

- 主名偏气质
- 副名偏玩法

## 13. 下一步最值得做的三件事

1. 重写项目首页说明，把当前项目真正的类型和卖点说清楚。
2. 统一对外表达，固定“历史题材轻策略 RogueLike”这套说法。
3. 做一版 30 秒内能解释清楚的宣传语和试玩引导，让玩家第一眼就知道这不是普通猜拳游戏。

## 14. 最终判断

这个项目值得继续做。

它最大的价值，不是某一个单点系统，而是已经形成了一个比较完整的产品骨架：

- 有可循环的局内玩法
- 有可扩展的时代章节
- 有可成长的局外系统
- 有足够强的题材辨识度

只要后续把“表达、节奏、视觉统一、核心爽点”四件事继续打磨，这个项目是有机会做成一个风格明确、体量可控、辨识度很强的独立策略 RogueLike 的。
